# Concepts

## Visual Reprogramming (VR)
- **Notation**: `fin(xi|θ) : X^T → X^P`
- **Definition**: A prompting technique that fixes a pre-trained model fP and modifies the input space by adding a learnable noise pattern δ to target images. The learned input transformation fin maps target domain images to the source domain space without modifying model parameters. Also called adversarial reprogramming.
- **Boundary conditions**: Applies when |YT| ≤ |YP| (target label space no larger than source). Fails on fine-grained tasks where input-space perturbations cannot bridge domain gaps (e.g., StanfordCars with 196 fine-grained classes).
- **Related concepts**: Model Reprogramming, Watermarking VR, Padding-based VR, Sample-specific Multi-channel Masks

## Sample-specific Multi-channel Masks (SMM)
- **Notation**: `fin(xi|ϕ, δ) = r(xi) + δ ⊙ fmask(r(xi)|ϕ)`
- **Definition**: A VR framework where, for each input image xi, a distinct three-channel continuous mask fmask(r(xi)|ϕ) ∈ R^dP is generated by a lightweight CNN parameterized by ϕ. The mask is multiplied element-wise with the shared learnable pattern δ and added to the resized image r(xi). The parameters ϕ (CNN) and δ (pattern) are jointly optimized.
- **Boundary conditions**: The mask generator CNN output is in R^dP (not restricted to {0,1}^dP like a binary mask). If the number of pooling layers l > 0, a patch-wise interpolation module is required to upsample the mask from H/2^l × W/2^l back to H × W.
- **Related concepts**: Visual Reprogramming, Mask Generator Module, Patch-wise Interpolation Module, Shared Pattern

## Mask Generator Module (fmask)
- **Notation**: `fmask(r(xi)|ϕ) : R^dP → R^dP`, parameterized by ϕ ∈ Φ
- **Definition**: A lightweight CNN that takes a resized target image r(xi) as input and outputs a three-channel mask. For ResNet (input 224×224): 5-layer CNN with layers [Conv(3→8)+BN+ReLU+MaxPool, Conv(8→16)+BN+ReLU+MaxPool, Conv(16→32)+BN+ReLU+MaxPool, Conv(32→64)+BN+ReLU, Conv(64→3)]. For ViT (input 384×384): 6-layer CNN adding an extra Conv(64→128)+BN+ReLU layer before the final Conv(128→3). All convolutions use kernel=3, padding=1, stride=1; all max-pooling uses kernel=2, stride=2. This produces an output of size H/2^l × W/2^l (with l=3 Max-Pool layers for default configuration).
- **Boundary conditions**: Contains only 26,499 parameters (ResNet) or 102,339 parameters (ViT), representing <0.23% of pre-trained model parameters. Initialized randomly at training start.
- **Related concepts**: Sample-specific Multi-channel Masks, Patch-wise Interpolation Module

## Patch-wise Interpolation Module
- **Notation**: Upsamples masks from `⌊H/2^l⌋ × ⌊W/2^l⌋` to `H × W`
- **Definition**: A non-parametric upsampling operation that enlarges each pixel value in the CNN output mask to a 2^l × 2^l pixel patch by copying (nearest-neighbor-like). Each patch of 2^l × 2^l pixels receives the same value as the corresponding low-resolution pixel. For non-divisible cases, values are mirrored from the nearest available patch. No floating-point arithmetic is needed; the operation is purely assignment/copying, so no backpropagation gradient is required through this module.
- **Boundary conditions**: Applied only when l > 0 (when the mask generator has at least one Max-Pool layer). Omitted when l = 0.
- **Related concepts**: Mask Generator Module, Sample-specific Multi-channel Masks

## Approximation Error
- **Notation**: `Errapx_D(F) = inf_{f∈F} E_{(X,Y)~D}[ℓ(f(X), Y)] - R*_D`
- **Definition**: In the PAC learning framework, the approximation error of hypothesis space F on distribution D is the gap between the minimum achievable error by any function in F and the Bayes risk R*_D = ∫(1 - sup_{y∈Y} Pr(y|x)) p_X(x)dx. A smaller hypothesis space generally yields larger approximation error.
- **Boundary conditions**: Requires that F1 ⊆ F2 to prove Errapx(F1) ≥ Errapx(F2) via Theorem 4.2. Does not directly guarantee lower excess risk (which also depends on estimation error).
- **Related concepts**: Hypothesis Space (Shared Mask), Hypothesis Space (SMM), Bayes Risk

## Hypothesis Space (Shared Mask) — Fshr
- **Notation**: `Fshr(f'P) = {f | f(x) = f'P(r(x) + M ⊙ δ), ∀x ∈ X}` where M ∈ {0,1}^dP
- **Definition**: The set of all functions achievable by shared-mask VR for a fixed pre-trained composition f'P = fout ∘ fP. The mask M is a constant binary matrix shared across all samples; δ ∈ R^dP is the trainable pattern.
- **Boundary conditions**: In padding-based VR, M has zeros at the image location and ones in the border region. In watermarking, M is a binary matrix with ones at effective δ locations.
- **Related concepts**: Hypothesis Space (SMM), Approximation Error

## Hypothesis Space (SMM) — Fsmm
- **Notation**: `Fsmm(f'P) = {f | f(x) = f'P(r(x) + fmask(r(x)) ⊙ δ), ∀x ∈ X}`
- **Definition**: The set of all functions achievable by SMM for a fixed f'P. The mask is a CNN function fmask: R^dP → R^dP producing continuous values per sample, and δ ∈ R^dP is shared. Key inclusion: Fshr(f'P) ⊆ Fsmm(f'P) because any constant M ∈ {0,1}^dP can be represented as a CNN output when the last layer weights are zero (output is the bias blast, which spans R^dP ⊇ {0,1}^dP).
- **Boundary conditions**: Requires fmask to be a CNN with appropriate kernel/padding so output size matches input size.
- **Related concepts**: Hypothesis Space (Shared Mask), Sample-specific Multi-channel Masks, Approximation Error

## Iterative Label Mapping (ILM)
- **Notation**: `f^{Ilm,(j)}_{out} : Y^P_sub → Y^T`, updated each epoch j
- **Definition**: An output mapping function that is updated every training epoch. At each epoch j, given the current fin(·|θ^(j)), it computes the frequency distribution d ∈ Z^{|YP|×|YT|} of predicted source labels for each target label, then greedily assigns the most frequent predicted source class to each target class via an injective mapping. Prevents duplicate assignments by zeroing out rows/columns after assignment.
- **Boundary conditions**: Requires |YT| ≤ |YP|. Converges when label assignments stabilize across epochs.
- **Related concepts**: Frequent Label Mapping, Random Label Mapping

## Watermarking VR (Bahng et al., 2022)
- **Notation**: `fin(xi) = r(xi) + M ⊙ δ` where r is bilinear upsampling
- **Definition**: A resizing-based VR method that upsamples target images to the source image size r(xi), then adds a learnable pattern δ modulated by a shared binary mask M. The mask M can be full (all-ones), narrow (1/8 width border), or medium (1/4 image area border).
- **Boundary conditions**: Three variants used as baselines: Full (M = all-ones, 224×224 mask), Medium (mask width=56, quarter image area), Narrow (mask width=28, 1/8 image size).
- **Related concepts**: Visual Reprogramming, Sample-specific Multi-channel Masks, Hypothesis Space (Shared Mask)

## Padding-based VR
- **Notation**: `fin(xi) = [zeros | xi | zeros] + M ⊙ δ` where zeros pad to source image size
- **Definition**: A VR method that centers the small target image within the source-resolution canvas and fills the border with learnable pattern δ (locations where M=1). The target image pixels are preserved unchanged. Used as the "Pad" baseline in experiments.
- **Boundary conditions**: Requires target images smaller than pre-trained model input size; only border region is modified by δ. Preserves original pixel values in the image region.
- **Related concepts**: Visual Reprogramming, Watermarking VR

## Excess Risk
- **Notation**: `Excess Risk = Errapx_D(F) + Errest_D(F, n)`
- **Definition**: The total excess risk of a learning algorithm decomposes into approximation error (how well the hypothesis class can fit the best possible function) and estimation error (how well the finite-sample ERM approximates the hypothesis-space minimum). SMM's lower approximation error is argued not to be offset by increased estimation error because the CNN adds <0.23% extra parameters and empirical overfitting analysis shows no significant difference in train-test gap.
- **Boundary conditions**: Estimation error can become significant if fmask is enlarged beyond the default lightweight architecture (see Table 11 for parameter scaling experiment on EuroSAT/ResNet-18).
- **Related concepts**: Approximation Error, Sample-specific Multi-channel Masks
