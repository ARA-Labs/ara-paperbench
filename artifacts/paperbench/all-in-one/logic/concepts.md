# Concepts

## Simformer
- **Notation**: $\text{Simformer}(\hat{x}^{M_C}, t, M_E) \rightarrow s_\phi^{M_E}(\hat{x}^{M_C}_t, t)$
- **Definition**: A probabilistic diffusion model that uses a transformer to estimate the score function of the joint distribution $p(\theta, x)$, conditioned on arbitrary subsets of variables. It encodes each variable as a token (identifier, value, condition state) and uses an attention mask to control dependency structure. A single trained Simformer can sample any conditional of the joint by reverse-diffusing unobserved variables while keeping observed ones fixed.
- **Boundary conditions**: Requires a simulator to generate $(θ, x)$ pairs; performance degrades with very few simulations (<1000); sampling is slower than normalizing flows (requires solving reverse SDE with ~500 steps); transformer evaluation scales quadratically with number of tokens.
- **Related concepts**: Score-based Diffusion Model, Tokenizer (SBI), Condition Mask, Attention Mask, Guided Diffusion

## Score-based Diffusion Model
- **Notation**: $s_\phi(\hat{x}_t, t) \approx \nabla_{\hat{x}_t} \log p_t(\hat{x}_t)$; reverse SDE: $d\hat{x}_t = [f(\hat{x}_t,t) - g(t)^2 s(\hat{x}_t,t)]dt + g(t)d\tilde{w}$
- **Definition**: A generative model that learns the score function (gradient of log probability density) of a data distribution at each noise level $t$, trained via denoising score-matching. Samples are generated by simulating the reverse stochastic differential equation from a noise distribution $p_T \approx \mathcal{N}(\mu_T, \sigma_T)$ to the data distribution $p_0$.
- **Boundary conditions**: Score is tractable only via approximation through score-matching; log-probability evaluation requires solving the probability flow ODE (computationally expensive). Assumes SDE does not introduce spurious correlations beyond those in the graphical model.
- **Related concepts**: Simformer, VESDE, VPSDE, Denoising Score-Matching Loss

## Tokenizer (SBI)
- **Notation**: Token $= [\text{embed}(\text{id}_i); \text{repeat}(v_i, d); \text{embed}(\text{metadata}_i); \text{embed}(c_i)]$
- **Definition**: A mapping from each scalar variable in $\hat{x} = (\theta, x)$ to a fixed-size vector token. Each token concatenates: (1) a learnable identifier embedding unique to that variable, (2) the scalar value repeated to match the token dimension, (3) an optional random Fourier embedding of the index set (for function-valued variables), and (4) a learnable condition-state embedding (shared vector for observed=True; zero vector for unobserved=False).
- **Boundary conditions**: For high-dimensional data (e.g., gravitational waves with 8192 elements), an external embedding network can compress data into a single token, losing individual condition-state control. Applies to scalar variables; vector variables require one token per element.
- **Related concepts**: Condition Mask, Simformer, Random Fourier Embedding

## Condition Mask
- **Notation**: $M_C \in \{0,1\}^d$; 1 = observed (clean), 0 = unobserved (noisy/latent). Partially noisy sample: $\hat{x}^{M_C} = (1-M_C) \cdot \hat{x}_t + M_C \cdot \hat{x}_0$
- **Definition**: A binary mask that specifies which variables are observed (conditioned on) and which are to be inferred (unobserved). During training, $M_C$ is randomly drawn each iteration from: the joint (all zeros), posterior (data=1, params=0), likelihood (data=0, params=1), or Bernoulli(p=0.3) and Bernoulli(p=0.7) random masks. At inference time, $M_C$ is set by the user to match the desired conditional.
- **Boundary conditions**: Variables with $M_C^{(i)}=1$ remain clean during diffusion; loss is computed only over unobserved variables ($M_C^{(i)}=0$).
- **Related concepts**: Tokenizer (SBI), Simformer, Attention Mask

## Attention Mask
- **Notation**: $M_E \in \{0,1\}^{d \times d}$; $M_E^{ij}=1$ means token $j$ can attend to token $i$. Dependency matrix: $D = \mathbf{1}(M_E^l > 0)$ for $l$-layer transformer.
- **Definition**: A binary mask applied to the self-attention mechanism of the transformer, encoding the known dependency structure (graphical model) of the simulator. Three variants: (1) dense (fully connected), (2) undirected (symmetric adjacency matrix of the undirected graphical model), (3) directed (adjacency matrix of DAG, dynamically updated using Webb et al. (2018) algorithm when conditioning changes dependencies). For $l$-layer transformer, reachable dependencies are given by $D = \mathbf{1}(M_E^l > 0)$.
- **Boundary conditions**: Undirected graphs allow all-to-all communication within connected components (given enough layers) but cannot enforce specific independence constraints. Directed graphs enforce independencies at $t=0$ but require dynamic updates per condition and may not faithfully represent dependencies at $t>0$ in general.
- **Related concepts**: Condition Mask, Simformer, Tokenizer (SBI)

## VESDE (Variance Exploding SDE)
- **Notation**: $f_\text{VESDE}(x,t) = 0$; $g_\text{VESDE}(t) = \sigma_{\min} \cdot \left(\frac{\sigma_{\max}}{\sigma_{\min}}\right)^t \cdot \sqrt{2\log\frac{\sigma_{\max}}{\sigma_{\min}}}$; perturbation kernel: $p(x_t|x_0) = \mathcal{N}(x_t; x_0, \sigma(t)^2 I)$ where $\sigma(t)^2 = \sigma_{\min}^2 \left(\frac{\sigma_{\max}}{\sigma_{\min}}\right)^{2t}$
- **Definition**: A score-based SDE where the variance explodes from $\sigma_{\min}^2$ at $t=0$ to $\sigma_{\max}^2$ at $t=1$. The drift is zero; only the diffusion term grows. Parameters: $\sigma_{\max}=15$, $\sigma_{\min}=0.0001$. Time interval: $[10^{-5}, 1]$.
- **Boundary conditions**: Primary SDE used in all main paper experiments. Valid assumption that it does not introduce cross-variable correlations beyond the graphical model.
- **Related concepts**: Score-based Diffusion Model, VPSDE, Denoising Score-Matching Loss

## VPSDE (Variance Preserving SDE)
- **Notation**: $f_\text{VPSDE}(x,t) = -\frac{1}{2}(\beta_{\min} + t(\beta_{\max}-\beta_{\min}))x$; $g_\text{VPSDE}(t) = \sqrt{\beta_{\min} + t(\beta_{\max}-\beta_{\min})}$; parameters: $\beta_{\min}=0.01$, $\beta_{\max}=10$
- **Definition**: A score-based SDE where noise is added to preserve approximate unit variance. Parameters: $\beta_{\min}=0.01$, $\beta_{\max}=10$. Time interval: $[10^{-5}, 1]$. Used as an alternative to VESDE; produces comparable but slightly different results (VESDE better on Two Moons, VPSDE slightly better on SLCP).
- **Boundary conditions**: Used in Appendix A3 comparisons; VESDE is default for main experiments.
- **Related concepts**: Score-based Diffusion Model, VESDE

## Denoising Score-Matching Loss
- **Notation**: $\mathcal{L}(\phi) = \mathbb{E}_{M_C,t,\hat{x}_0,\hat{x}_t}\left[\left\|(1-M_C)\cdot\left(s_\phi^{M_E}(\hat{x}_t^{M_C},t) - \nabla_{\hat{x}_t}\log p_t(\hat{x}_t|\hat{x}_0)\right)\right\|_2^2\right]$
- **Definition**: The training objective for the Simformer. For each sample, a noise level $t \in [10^{-5},1]$ and condition mask $M_C$ are drawn randomly. The model predicts the score of unobserved variables; the loss is zero for observed (clean) variables. The weighting function $\lambda(t)$ can be set to $g(t)^2$ for the VESDE.
- **Boundary conditions**: Requires knowledge of the conditional score $\nabla_{\hat{x}_t}\log p_t(\hat{x}_t|\hat{x}_0)$, which is analytically available for both VESDE and VPSDE. Loss is computed only over unobserved variables (where $M_C^{(i)}=0$).
- **Related concepts**: Simformer, VESDE, VPSDE, Score-based Diffusion Model

## Guided Diffusion (Interval Conditioning)
- **Notation**: $s_\phi(\hat{x}_t, t | c) \approx s_\phi(\hat{x}_t, t) + \nabla_{\hat{x}_t} \log\sigma(-s(t)\cdot c(\hat{x}_t))$; constraint: $c(\hat{x}) \leq 0$; scaling: $s(t) = 1/\sigma(t)^2$
- **Definition**: A technique to condition diffusion model sampling on soft constraints (e.g., intervals). The score is modified by adding the gradient of a sigmoid-penalized constraint function evaluated on a denoised estimate $\hat{x}_0$. Combined with optional self-recurrence (parameter $r$ controlling forward-backward correction steps). For upper-bound $u$: $c(\hat{x}) = \hat{x} - u$; for lower-bound $l$: $c(\hat{x}) = l - \hat{x}$.
- **Boundary conditions**: Approximate method; accuracy improves with self-recurrence at cost of $r$-fold computation increase. General guidance (not RePaint) required for non-standard constraints. Scaling function must match the SDE variance schedule.
- **Related concepts**: Simformer, Score-based Diffusion Model, Condition Mask

## Classifier Two-Sample Test (C2ST)
- **Notation**: $\text{C2ST}(P, Q) \in [0.5, 1.0]$; 0.5 = identical distributions, 1.0 = perfectly separable
- **Definition**: An evaluation metric that trains a binary classifier (random forest with 100 trees) to distinguish between samples from two distributions using 5-fold cross-validation accuracy. Used to compare Simformer-generated posterior samples against MCMC ground-truth samples. A score of 0.5 indicates the approximation is indistinguishable from the ground truth.
- **Boundary conditions**: Requires sufficiently many samples to train the classifier; evaluated on 10 ground-truth posteriors for benchmark tasks and 100 randomly sampled conditionals for arbitrary conditional evaluation. Sensitive to number of samples.
- **Related concepts**: Simformer, Denoising Score-Matching Loss
