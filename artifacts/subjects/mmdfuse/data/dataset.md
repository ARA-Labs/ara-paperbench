# Data and provenance

The locally executed Gaussian mixture is generated by the pinned MIT-licensed author sampler. It uses no natural dataset, image collection or pretrained model. Exact parameters, input keys and content digests are retained in the protocol and per-repetition records. Data arrays themselves were not retained, so the records do not claim a byte-only replay of generated samples without their pinned generator.

The paper also studies perturbed uniforms, GalaxyMNIST and CIFAR image collections. Their source descriptions and released aggregate outputs are represented. No raw image dataset was fetched for this compilation, and the repository source license is not treated as a blanket license for external image assets. Image comparisons remain author-reported.

The paper, notebook outputs, result arrays, protocol expectations and this artifact contain outcome-bearing information. A separately verified masked view is required before a project inner-loop agent can consume the candidate.
